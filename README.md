# Only between us

A scroll-driven introduction to end-to-end encryption, built with Vite and vanilla JavaScript.

## Run locally

Install Node.js, then run:

```sh
npm install
npm run dev
```

Create a static production build with `npm run build`. Preview it with `npm run preview`.

## Deploy

The `dist/` directory contains the static site after a build. It can be deployed to GitHub Pages, Netlify, or another static host. For GitHub Pages, configure the repository's Pages source to use a deployment workflow that publishes `dist/`.

## About

The lesson covers plain text, public/private keys, shared secrets, local encryption, ciphertext delivery, and local decryption. The phone tilt is implemented in CSS and JavaScript; no third-party tilt library is required.
